# Interface design

Use the Guild Raid Roadmap as a model. It starts with the next checkpoint for the selected team, shows each character's immediate target, and links to the place where the player can act. Later checkpoints, full costs, and sources open on demand.

- Start with the player's current goal and the next action. Use the synced roster, inventory, and active plan to determine what belongs on the page.
- Show the few items that can affect this decision. Keep broader catalogs and other plans available through their own views.
- Keep recommendations visible when players choose an alternative. Give them a clear way to edit the current selection and update every dependent view immediately.
- Put prerequisites and practical consequences beside the action they affect. Move detailed reasoning, sources, and future investment into disclosures.
- Reuse the app's existing navigation, portraits, rank badges, and collapsible sections. Check the default view on a narrow screen and make edits keyboard-accessible.
- Confirm actions in place and name the changes when the result would otherwise be hard to see.
